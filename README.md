# Breast Cancer Diagnosis using Machine Learning
This project demonstrates a machine learning pipeline for classifying breast cancer tumors using scikit-learn, covering Exploratory Data Analysis (EDA), feature selection, and model training. It is based on the Breast Cancer Wisconsin Diagnostic Dataset.

Dataset Information:

Dataset: Breast Cancer Wisconsin (Diagnostic)
Source: UCI Machine Learning Repository
Citation:
Wolberg, W. H., & Mangasarian, O. L. (1992). Breast Cancer Wisconsin (Diagnostic) Data Set. UCI Machine Learning Repository. Retrieved from https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic
